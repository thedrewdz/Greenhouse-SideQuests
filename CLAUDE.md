# Greenhouse-SideQuests

Before working on anything in this repository, reference the **Greenhouse-Documentation** repo:
https://github.com/thedrewdz/Greenhouse-Documentation — also available locally at `D:\Code\Greenhouse\docs`
(architecture.md, device-model.md, mqtt-topics.md, rest-api-standards.md, control-unit-model.md, ADRs, etc.).

All projects in this repository (side-quests) are **proof-of-concept (POC) spikes**. Treat Greenhouse-Documentation
as the source of truth for architecture, device/data models, MQTT topics, and API standards — check it before
designing or implementing anything that touches those areas, even though a POC itself may take shortcuts.

If the local docs at `D:\Code\Greenhouse\docs` are stale relative to GitHub, prefer GitHub as authoritative.
